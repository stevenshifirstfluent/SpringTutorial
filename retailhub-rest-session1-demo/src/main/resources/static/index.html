@Controller vs @RestController — Same Spring MVC Infrastructure

@Controller

Returns a view name by default. Spring/Thymeleaf prepares the HTML on the server.

return "mvc-products"; Open the Thymeleaf result →

@RestController + JavaScript UI

The controller returns data. The browser's JavaScript calls the API and creates the UI from JSON.

fetch('/api/products') → JSON → renderProducts() Open the raw JSON result →
Teaching helper: POST /api/demo/reset resets H2 data. It is not part of the Product business API.
