Spring Validation & Global Exception Handling

Trigger different validation failures and observe which global exception handler processes the request.

1 Request Body Validation

Demonstrates Bean Validation on: @Valid @RequestBody User

Expected exception: MethodArgumentNotValidException
POST /api/users/register

2 Controller Parameter Validation

Demonstrates a validation constraint directly declared on a Spring MVC controller method parameter. 

@PathVariable
@Min(
    value = 1,
    message =
        "User id must be at least 1"
)
Long id
Expected exception: HandlerMethodValidationException
GET /api/users/{id}

3 Service Method Validation

Demonstrates method validation on a Spring service annotated with @Validated . 

@Service
@Validated
public class ValidationDemoService {

    public String checkUserId(
        @Min(1)
        Long id) {
        ...
    }
}
Expected exception: ConstraintViolationException
GET /api/validation/service/{id}

4 Data Binding Failure

Demonstrates a Spring DataBinder conversion failure. The target property is an Integer, but the request sends text such as abc .

Expected exception: BindException
POST /api/validation/bind?age=...
